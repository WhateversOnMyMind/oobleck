Oobleck is a personal anime player for Windows, Android and iOS.

## What's in it
- Streaming with server fallback, resume, auto-next and skip intro / outro
- Downloads for offline viewing (the **Downloaded** tab)
- Korean subtitles found and turned on automatically, with a sync offset (ms) saved per season
- Anime4K real-time upscaling
- Optional watch-history sync between devices: tap **Sign in** at the top right of Home (user ID and password only)
- English and Korean UI, chosen on first launch (Settings > Language to change it)
- Picture modes Fit / Zoom to fill / Stretch for older 4:3 shows

## Install
- **Windows**: download `oobleck-windows.zip`, unzip, run `oobleck.exe`
- **Android**: install `app-arm64-v8a-release.apk` (most phones). Allow "install unknown apps" for your browser or
  file manager when asked. Later versions install over it and keep your downloads and history
- **iOS**: `oobleck-ios-unsigned.ipa` must be signed with your own Apple ID by a sideloading tool such as AltStore or
  Sideloadly. With a free Apple ID the app has to be refreshed every 7 days

## 한국어
- 윈도우: `oobleck-windows.zip` 압축을 풀고 `oobleck.exe` 실행
- 안드로이드: `app-arm64-v8a-release.apk` 설치 (대부분의 휴대폰)
- iOS: AltStore나 Sideloadly로 `oobleck-ios-unsigned.ipa`를 본인 Apple ID로 서명해 설치 (무료 계정은 7일마다 갱신)
- 처음 실행할 때 언어를 고르고, 홈 오른쪽 위 **로그인**으로 기기 간 시청 기록을 동기화할 수 있어요
