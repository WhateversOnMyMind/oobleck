# Decisions

- Storage: `hive_ce` (pure Dart, no native sqlite to bundle on Windows/Android; I can't build those targets locally, so the lowest-risk option wins). Entities are JSON maps in boxes.
- State: `flutter_riverpod` v3.
- Flutter stable 3.47.9 / Dart 3.13 installed to /opt/flutter in the build sandbox.
- Live anikoto probing from the build sandbox was blocked by the sandbox policy; source layer is developed against fixtures (SYNTHETIC where noted). Use Settings > Advanced > Source diagnostics against the live site.
- Android release signing uses the debug keystore (sideloading only).
- Dropped permission_handler: it requires compileSdk 37 (AGP max 36) and the foreground-service plugin handles the notification permission itself.
- Anime4K is off until the user picks a preset in the player; 'Mode A (Fast)' is the recommended/default preset when enabling (heavy on phones). Shaders from bloc97/Anime4K (MIT) bundled with its licence.
- 2026-11-12: Live captures go in `test/fixtures/anikoto/live/` next to the SYNTHETIC ones; the synthetic tests stay because they cover cases the live show lacks (fillers, vidtube, Kiwi, plain sources).
- 2026-11-12: Show slugs come from the URL segment after `/watch/` because home cards link to episode pages (`/watch/<slug>/ep-N`).
- 2026-11-12: CI pins Flutter 3.47.9. Unpinned `stable` moved to 3.50.0, which deprecates `package:flutter/material.dart` (analyze fails) and needs AGP 9.1.1+. Upgrade deliberately later (material_ui migration + AGP bump).
- 2026-11-12: Android release signing uses a fixed PKCS12 key (alias `oobleck`) from CI secrets, kept outside the repo; falls back to the debug key with a CI warning. versionCode = CI run number so newer builds always install as updates.
- 2026-11-12: The Korean finder looks up the Japanese title (and Korean synonyms) on AniList by MAL id, because Anissia rarely matches English titles; season markers are stripped when the full title has no match.
- 2026-11-12: Korean subtitles load automatically. Anissia only lists each fansubber's latest post, so the finder reads the fansubber's blog feed (Tistory RSS, Blogspot JSON) for the "<show> N화" post, then falls back to the latest post's season pack. Show matching must agree on season and title, otherwise nothing loads (no wrong-season subtitles). Naver blogs are skipped (empty feeds, redirecting posts).
- 2026-11-12: The subtitle sync offset is stored per show (= per season) in ms and applies only to Korean/imported tracks; the site's own tracks are already in sync and always play with no offset.
- 2026-11-12: Android (Flutter-drawn) subtitle size = size setting x screen height / 720 x 0.75, matching mpv's 720p-relative font size on desktop; the default 46 gives ~20 dp on a phone. Fit mode is per show because only old 4:3 shows need it.
- 2026-11-12: Sync accounts are user ID + password. The app stretches the password (PBKDF2-SHA256, 100k rounds, salt = user ID) and the Worker stores SHA-256(salt + key): Workers' free plan has ~10 ms CPU per request, too little for server-side PBKDF2, and the guess cost stays with the attacker. No password reset (no e-mail).
- 2026-11-12: Sync is last-write-wins per episode on the client's `updatedAt`; clears are tombstones with the client time, so stale uploads from other devices cannot resurrect cleared history. The server URL comes from `--dart-define=OOBLECK_SYNC_URL` (repo variable) or the sign-in dialog, never committed.
- 2026-11-12: UI text is one `Strings` class with English and Korean side by side per entry (not ARB/gen-l10n): no codegen, both languages can't drift apart, and non-widget code (player toasts) can use it via the language setting.
- 2026-11-12: The first launch shows a language picker until a language is saved; existing installs see it once after updating.
- 2026-11-12: iOS builds unsigned in CI (no Apple account in the repo); installing needs sideloading with the owner's Apple ID.
- 2026-11-27: Manga comes from 11toon (plain HTML, no bot protection, checked live). It sits behind `MangaSource`, separate from the anime `Source`, because the shapes differ (pages vs streams). Storage keys carry the source id (`toon11:<is>`) so another site can be added later.
- 2026-11-27: The reader follows Mihon's feature set (library with categories, updates, history, browse, per-series reading mode, tap zones, long-strip and paged modes, downloads) but is our own Flutter code; Mihon (Apache-2.0) and the Keiyoushi toon11 extension were read for reference only.
- 2026-11-27: "Automatic" reading mode decides from the first page: strips taller than 2.2x their width scroll as a webtoon, book pages turn right to left (most paged titles on 11toon are Japanese manga). One tap in the reader menu changes it for the series.
- 2026-11-27: Chapter lists are fetched page 1 first, then the remaining pages 4 at a time (One Piece: 14 pages in ~4 rounds instead of 14 in a row).
- 2026-11-27: Upscaling is a GPU spatial filter (FSR 1.0 EASU port plus an RCAS-style sharpen with a range clamp) through Flutter fragment shaders, not a neural model: it runs in real time on every platform with no model download. It only kicks in when a page is drawn larger than its pixels.
- 2026-11-27: The long-strip reader uses `scrollable_positioned_list` (Google, BSD) to jump to a page and know exactly which page is on screen; plain ListView cannot do either with images of unknown height.
- 2026-11-27: Offline chapters are plain image files (`<Pictures>/Oobleck Manga/<series>/<chapter>/001.jpg`), not CBZ, so any image viewer can open them and pages can be read while the rest download. Chapter folders carry the chapter id (`12화 (4521)`) so two chapters with the same title never share one.
- 2026-11-27: Pinch zoom in the reader is touch only. On desktop the mouse wheel scrolls (long strip) and double click zooms (pages); Flutter's InteractiveViewer would otherwise zoom on every wheel notch.
- 2026-11-27: Undo is offered only for changes that can be reversed (watched marks, progress, recent searches, library removal). Deleting files always asks first instead, with Cancel focused so Enter never deletes.
- 2026-11-27: Esc, Alt+Left, the keyboard Back key and the mouse back button close the top page, sheet or dialog everywhere; the player and reader handle Esc themselves first (menu, then fullscreen, then back).
